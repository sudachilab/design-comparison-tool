# 設計書比較ツール

5種類のExcelファイル（.xlsx/.xls）をブラウザで読み込み、文字情報・セル位置・縦横の結合セルを自作グリッドで表示します。セルの罫線は.xlsxファイルで線種・太さ・色を反映します。画像・図形などの表示には対応していません。

## 起動方法

1. このフォルダをVS Codeで開きます。
2. VS CodeのLive Server拡張で `index.html` を開きます。またはフォルダ内で `python -m http.server 8000` を実行し、`http://localhost:8000` にアクセスします。
3. 要件定義書・基本設計書・外部設計書・詳細設計書・内部設計書を選択してください。複数シートは各プルダウンで切り替えます。
4. 概要番号（例: K1、K1-1）は番号ごとに色分けして表示します。基本設計書の番号セルをクリックすると、要件定義書を除く設計書で同じ概要番号のセルへ移動します。
5. 検索欄に文字や概要番号を入力すると、5種類の設計書をまとめて検索できます。

Googleスプレッドシートは **ファイル → ダウンロード → Microsoft Excel (.xlsx)** で保存してからアップロードしてください。

## 構成
- `index.html`: ページ構造、ライブラリ読込
- `css/style.css`: UI、グリッド線、レスポンシブ表示
- `js/main.js`: 5種類のファイル選択、シート切替、概要番号連動、画面制御
- `js/excelReader.js`: Excel解析とセル書式の読込
- `js/gridRenderer.js`: グリッド、罫線、結合セルの描画
- `js/comparison.js`: キーワード検索・強調
- `js/overviewNumbers.js`: 概要番号の抽出と色決定

## 注意
- SheetJSをCDNから読み込むため、初回起動時はネット接続が必要です。
- ファイル内容はサーバーへアップロードせずブラウザ内で処理します。
- 巨大なシートは描画負荷を避けるため10万セルで制限しています。
- 罫線表示は`.xlsx`のみ対応します。斜線は表示せず、一点鎖線系は破線で近似します。
- セル内容の表示はテキストとして行い、Excelの数式は原則として保存済みの表示値を使います。
- Google Drive API連携や自動的な設計対応付けは未実装です。
